# MedChem Community (GitHub Pages template)

A lightweight, static HTML/CSS/JS site you can deploy instantly with GitHub Pages.

## Quick start
1. Create a new repo (e.g., `medchem-community-site`)
2. Copy all files from this template into the repo root
3. Commit + push

## Enable GitHub Pages
- Go to **Settings → Pages**
- Choose a source:
  - **Branch:** `main` (or `master`)
  - **Folder:** `/ (root)`
- Save, then wait for the Pages URL to appear.

## Customize
- Update brand name in `index.html` and other pages
- Edit events in `assets/data/events.json`
- Replace `mailto:you@example.com` with your email address
- Add your real social links in the footer

## Notes
- `.nojekyll` is included to keep assets working cleanly on GitHub Pages.
